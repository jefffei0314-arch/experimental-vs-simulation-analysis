# Experimental vs Simulation Analysis

This project compares experimental and simulation data using Python.

## Features
- Interpolation of simulation data to match experimental time points
- Error analysis (Average Error, Maximum Error)
- Visualization of comparison results
- Highlighting of maximum deviation

## Tools Used
- Python
- pandas
- matplotlib
- numpy

## Output
- Comparison plot between experiment and simulation
- Error metrics printed in console

## Purpose
This project demonstrates basic data analysis and visualization skills, with applications in engineering validation and model comparison.
